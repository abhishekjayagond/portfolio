# Portfolio

A personal single-page portfolio website designed to showcase software engineering projects, technical skills, and core computer science foundations.

Live site: [abhishekjayagond.vercel.app](https://abhishekjayagond.vercel.app/)

## Stack

* React
* Tailwind CSS
* Vite
* Vercel

## Features

* Responsive, single-page layout
* Dark theme UI with clean spacing and subtle visual components
* Featured project cards showcasing state detail, local threading, and PreparedStatements
* Technical skills index grouped by domain
* Academic CS foundations and certifications display

## Local Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This portfolio is automatically built and deployed on Vercel on push to the `main` branch.
